# R3 回测：选品「刚从低点涨上来」（2026-11-23）

> 起因见 intent（未公开）。标准在跑之前定死、和 R2 相同：H1、H2 两段都要满足「标出样本的 r14 中位数更低，而且 P(r14<−5%) 高出至少 5 个百分点」。命令 `uv run python -m skinpulse backtest`，只读库。

**结论：R3 通过**（下面「## R3」一节）。从近 60 根最低涨了 ≥ 30% 的样本，H1 吃亏概率高 8.6 个百分点，H2 高 17.5 个百分点。上线为选品的「观望」理由，阈值进 `[valuation] rebound_window / rebound_max`。

「炒过」（一年最高 ≥ 最低 × 3）在 intent 的探查里两段都不过（只高 2～4 个百分点），这里只列在明细表里作描述，不进结论。

局限同 [2026-10-09 报告](2026-10-09-valuation-backtest.md)：只有一年、这一年大盘跌了约一半、模板都是用户挂过单的；这次的样本扩到了选品取过日线的模板（701 个）。
