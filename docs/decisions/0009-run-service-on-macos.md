# 0009. 服务改在 macOS 上运行，Windows 实例退役

- 日期：2026-09-24
- 状态：生效
- 拍板：用户

## 背景

M1–M3a 都是在 Windows 11 家庭版上开发和运行的。这台机器上的自启走启动目录，没有失败重启（[ADR-0005](0005-windows-autostart-startup-folder.md)），监控已经停摆过好几次（08-31～09-05、09-08～09-20、09-23 起）。用户决定以后在 Mac 上跑服务，并在 Mac 上继续开发。

## 决定

- 服务的**唯一运行实例**迁到 macOS。迁移完成后，Windows 上的实例要停掉，并删除启动目录里的 `SkinPulse.lnk`。
- **任何时候只能有一个实例在跑。** 两个实例会各推一遍告警和简报，对悠悠的请求量也会翻倍，容易触发风控。
- 数据库、`settings.toml`、`data/steamdt_base.json` 从 Windows 拷到 Mac，历史数据、告警状态和简报记录都延续下去。凭据不拷文件，在 Mac 上重新录入钥匙串。
- macOS 的自启方式、睡眠策略等适配工作在 Mac 上做，范围见 intent（未公开）。

## 否决的方案

- 两台机器同时跑、互为备份：会重复推送、请求量翻倍；要做主备切换得先有锁或选主，不值得。

## 影响

- ADR-0005（Windows 启动目录）只在 Windows 上适用。迁移完成后，它描述的不再是生产环境。
- CLAUDE.md、README 里的 Windows 专属说明保留，但要标明适用平台，并补上 macOS 的对应说明。
- Mac 在睡眠时服务不会跑：00:00 的简报靠「启动补发」和 `misfire_grace_time` 补；23:50 的价格快照错过就没有了。睡眠策略由 Mac 上的适配任务决定。
