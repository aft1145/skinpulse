# 0014. 「值不值得买」分三期做，建议先过回测再上线

- 日期：2026-09-27
- 状态：生效
- 拍板：用户（采纳 intent（未公开） 的方案 B）

## 背景

用户想结合历史价格判断饰品值不值得买，目的是赚差价。

- 现有 429 张求购单的价格平均只有悠悠在售最低价的 47%，纸面差价很大。
- 外部研究显示饰品的日收益基本不可预测。
- 最大的不确定在三处：多久能成交、7 天交易锁期间的跌幅、政策冲击。

## 决定

分三期做，每期一个分支，各有自己的 spec 和 plan。

1. **一期：给现有挂单加「描述」**
   - 存自有日线（`daily_bar`），记录成交事件（`remaining_qty` 减少的时候）。
   - 描述标签：价位、趋势、相对大盘、波动（EWMA）、出手难易、数据够不够。
   - 两个平台都算扣费后的净差价：悠悠 1%，BUFF 1.5%（2026-04-14 起统一）；另扣提现 1%。再算 7 天内的坏情况。
   - 以上放进总览和详情页。
2. **二期：先回测，再上线建议**
   - 自己用 pandas 写 walk-forward 回测，校准阈值，并和「不筛选」这个基准比。
   - 结果写进 `docs/research/`。
   - 通过了，才打开这几条建议：保持、可以加价、考虑降价、考虑撤单、不评价。
3. **三期：小范围选品**
   - 用户按品类圈池子，默认排除印花、挂件、收藏品、武器箱、布章、涂鸦；池子上限 500 个模板。
   - 后台任务去跑，算出建议求购价上限，给「可以挂 / 观望 / 不建议」。

各项参数的默认值见 intent 的「默认参数」一节。所有建议只作参考，改价、撤单由用户自己操作，对悠悠仍然只读。

## 否决的方案

- **只做描述、不给建议**：满足不了「先描述、再建议」的要求。
- **一步到位，建议直接上线、回测以后补**：回测之前的阈值没有依据，和「结论必须能追溯」冲突。
