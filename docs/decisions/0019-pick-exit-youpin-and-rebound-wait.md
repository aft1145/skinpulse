# 0019. 到手价只按悠悠算；选品里刚从低点涨上来的判观望

- 日期：2026-11-23
- 状态：生效
- 拍板：用户（只在悠悠出货；选了「炒过的不推」「刚涨完的不推」「到手价只算悠悠」，并指出不该只拿一年前比）

## 背景

11-23 的选品把两个法玛斯判成「可以挂」：一年前几块钱、春天炒到十几倍、10 月跌回来、11 月又涨了六七成。规则只看 7 天最坏会跌多少，不看是不是刚涨上来；到手价还取了 BUFF 的价。见 intent（未公开）。

## 决定

- `[valuation] exit_platforms` 默认 `["YOUPIN"]`：到手价只按悠悠在售算。总览价位视图、建议、选品都用它。
- 选品结论加一条：现价比近 60 根最低收盘高 ≥ 30%（`rebound_window` / `rebound_max`）→ 观望。按 ADR-0014 先回测（R3，标准同 R2），两段都过：[报告](../research/2026-11-23-pick-rebound-backtest.md)。
- 「炒过」（一年最高 ≥ 最低 × 3）回测两段都不过，只在表格里作说明。

## 否决的方案

- **拿一年前的价当基准判「炒过」**：起点日期是任意的，用户也指出近期低点（10 月中旬）才是该比的；改成和起点无关的「从近期低点反弹多少」。
- **悠悠、BUFF 哪家到手多算哪家**：用户不在 BUFF 卖，差价被高估。

## 影响

- `analysis/valuation.py`（`exit_platforms`、`rebound`、`amp`）、`analysis/pick.py`（结论）、迁移 0013、[价位 spec §9b.3](../superpowers/specs/2026-09-27-price-position.md)。
- 总览价位视图的「可以加价」建议没用 R3；要用另写 intent。R3 和 R1 一样每季度跟着回测重跑。
