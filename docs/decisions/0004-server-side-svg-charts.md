# 0004. 看板图表服务端生成 SVG，不引前端图表库

- 日期：2026-09-23
- 状态：被 [0013](0013-echarts-replaces-server-svg.md) 取代
- 拍板：补记。原始讨论未留档，下面的理由是按实现和 README 推断的，用户可修正

## 背景

spec 原定本地 ECharts。看板需要的图只有 K 线、均线、走势折线，数据量小（一年日线约 365 根）。

## 决定

`web/charts.py` 在服务端直接生成 SVG；涨红跌绿；K 线纵轴按实体定范围，离谱影线截断并在图上写明截断了几根、极值多少。

## 否决的方案

- ECharts：要下载并随仓库分发一个大体积前端库，为几张静态图不值得；交互（缩放、悬停）目前用不上。

## 影响

- 不需要前端构建或静态库；图表逻辑可以用普通单元测试覆盖。
- 以后需要交互式图表（缩放、十字光标）时再重新考虑。
